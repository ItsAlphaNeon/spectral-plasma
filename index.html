macOS, still

Export a PNG at This display, then right-click it in Finder and choose Set Desktop Picture, or add it in System Settings › Wallpaper.

macOS, animated

macOS has no built-in way to use your own animated wallpaper. Export Live HTML and open it in a web-page wallpaper app such as Plash, or use the MP4 loop with any video-wallpaper app. The loop is seamless: the last frame leads straight back into the first.

Windows, Wallpaper Engine

Pre-rendered video renders the loop to an H.264 video at the resolution and frame rate above, so Wallpaper Engine only decodes it on the GPU's video engine instead of running the shader. Unzip it into a folder inside wallpaper_engine\projects\myprojects and it shows up in Wallpaper Engine with its title and preview. A longer loop length means the video wraps around less often.

Live shader renders in real time and stays editable. Unzip it, then in Wallpaper Engine choose Open Wallpaper › Open from File and pick index.html. Element, form, seed, speed and exposure stay editable in its properties panel, and pasting a settings code there loads any look made in this app. The same HTML also works in Lively Wallpaper.

About the data

Each source uses its prominent lines between 370 and 800 nm, with wavelengths from the NIST Atomic Spectra Database and relative intensities that are approximate and normalized per element. Paste a NIST table above to use exact values.
